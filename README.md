# Skyblock-Mods

Eine Sammlung von Forge-Mods für **Minecraft 1.8.9**, die ich für Hypixel Skyblock verwende.
Alle Angaben stammen direkt aus den `mcmod.info`-Dateien der jeweiligen Jars.

## Enthaltene Mods

| Mod | Version | Autor(en) | Beschreibung |
|---|---|---|---|
| [NotEnoughUpdates](https://github.com/Moulberry/NotEnoughUpdates/) | 2.0.0 | Moulberry | Zeigt Rezepte und nützliche Infos für Hypixel Skyblock. |
| [Skytils](https://github.com/Skytils/SkytilsMod) | 1.2.6 | My-Name-Is-Jeff, Sychic | Umfangreiche Utilities für Skyblock. |
| [Dungeon Rooms Mod](https://discord.gg/7B5RbsArYK) | 3.3.1 | _risk (aka Quantizr) | Secret-Waypoints und Raumnamen in Skyblock Dungeons. |
| Apec | 1.10.2 | BananaFructa | Überarbeitet die Spiel-GUI für Hypixel Skyblock. |
| [ChatTriggers](https://www.chattriggers.com) | 2.1.5-1.8.9 | FalseHonesty, Ecolsson, kerbybit | Framework für Live-Scripting und Client-Modifikation via JavaScript. |
| SoopyV2Forge | 1.1 | Soopyboo32 | Rendering-Optimierungen für das ChatTriggers-Modul SoopyV2. |

## Weitere Dateien

- `config.rar` – meine Konfigurationsdateien für die oben genannten Mods.

## Installation

1. **Minecraft Forge für 1.8.9** installieren und das Profil einmal starten, damit der Ordner `mods` angelegt wird.
2. `%appdata%\.minecraft\mods` öffnen (Windows) bzw. `~/.minecraft/mods` (Linux/macOS).
3. Die gewünschten `.jar`-Dateien aus diesem Repository dorthin kopieren.
4. Minecraft mit dem Forge-1.8.9-Profil starten.

> **Hinweis:** SoopyV2Forge setzt ChatTriggers samt dem Modul SoopyV2 voraus.
